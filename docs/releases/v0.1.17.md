## OneSync v0.1.17

- 修复反向代理终止 HTTPS 时，管理页写请求因后端误判为 HTTP 而出现“请求来源与管理地址不一致”的问题。
- 通过 `ONESYNC_FORWARDED_ALLOW_IPS` 显式配置可信代理来源，保留 Host、Origin 与跨站请求校验。
- Unraid 模板和 Compose 示例补充代理来源配置；同步目录与授权数据保持不变。
