## OneSync v0.1.8

### 更新内容

- 管理页重构为 React + TypeScript + 原生 CSS，采用深色紧凑的 OneSync 控制台界面。
- 保留同步范围选择、设备代码授权、持续/单次同步、受控重同步、进度、通知、日志与关于页。
- 移除内置登录口令和浏览器会话；管理页仅适用于受信任的 LAN/VPN 网络边界。
- 启动时将 `/onedrive/conf` 与 `/onedrive/data` 挂载根目录设为 `drwxrwxrwx`，并使用 `umask 000`。

### 升级说明

升级后不再需要 `ONESYNC_ADMIN_TOKEN`。可从 Compose、DockerMan XML 与容器环境变量中移除它。请继续限制 `8098` 到可信 LAN/VPN，且不要暴露到公网。
