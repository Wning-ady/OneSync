## OneSync v0.1.6

本版本重点处理重同步期间的“看起来卡住”和管理页长时间刷新卡顿问题。

### 更新内容

- 管理页健康检查改为本地快速状态，不再等待 Microsoft Graph 网络请求。
- 降低常规页面轮询频率；同步进行中保持更快刷新，并阻止重复刷新请求叠加。
- 日志接口限制为最近记录，页面按下载、上传、完成、警告和错误分色显示。
- 重同步增加云端条目扫描数、待下载文件数与当前阶段文字，长目录扫描期间不再只显示“安全检查中”。
- 下载 HTTP 403 失败按文件记录中文原因，明确提示检查云端权限、共享状态或重新授权，且不会删除本地文件。
- 界面改为紧凑深色设置面板，改善目录、进度、操作和日志的层级。

### 已知同步限制

Linux/Unraid 单个文件名最多 255 个 UTF-8 字节。云端文件名超过此限制时，请先在 OneDrive 中缩短名称再重同步。HTTP 403 文件需要在 OneDrive 中确认文件权限或复制为新文件后重试。
